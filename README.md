# الموقع الشخصي — محمد أنور يحي أحمد عمران

موقع شخصي احترافي يجمع بين السيرة الذاتية الإلكترونية، معرض المشاريع، الخدمات التقنية، المهارات، والمؤهلات والشهادات.

## المميزات
- تصميم عصري داكن/فاتح (Dark/Light) مع لمسات زرقاء وسماوية.
- دعم كامل للغة العربية (RTL) والإنجليزية (LTR) مع زر تبديل فوري.
- متجاوب بالكامل مع الكمبيوتر والهاتف والأجهزة اللوحية.
- حركات انتقالية وتأثيرات بصرية هادئة + خلفية جسيمات تفاعلية.
- نافذة تفاصيل لكل مشروع، وزر "طلب خدمة" يوجّه إلى نموذج التواصل.
- نموذج تواصل مع تحقق كامل من صحة البيانات + حماية من الرسائل المزعجة (Honeypot).
- تحسين محركات البحث (SEO): Meta tags، Open Graph، Twitter Cards، Structured Data (JSON-LD).
- زر **طلب تنزيل السيرة الذاتية PDF** — بموافقة صاحب السيرة (لا يوجد تنزيل مباشر).
- **محتوى حيّ قابل للتعديل** — أي تعديل من لوحة التحكم يظهر على الموقع فوراً (بدون إعادة نشر).

## المسارات (نطاق واحد)
| المسار | الصفحة | الوصف |
| ------ | ------ | ----- |
| `/`      | `index.html` | صفحة الترحيب: الاسم + زر **الرئيسية** + مدخل **مخفي** للوحة التحكم. |
| `/home`  | `home.html`  | موقع السيرة الذاتية مباشرة. |
| `/admin` | `admin.html` | لوحة التحكم (محمية بكلمة مرور). |

> مدخل اللوحة **غير معلن**: نقطة قفل خفية في زاوية الصفحة، أو `Ctrl/Cmd + Shift + A`، أو كتابة كلمة `admin`. وكلمة المرور تُفرض على الخادم في كل الأحوال.

## 🎛 لوحة التحكم (تعديل الموقع بدون كود)

افتح الرابط:
```
https://<رابط-موقعك>/admin
```
**محمية بكلمة مرور** — تُفرض على الخادم. أدخل كلمة المرور لفتح اللوحة (تسجيل الدخول يمنحك جلسة مؤقتة 12 ساعة).

**ماذا تستطيع أن تفعل من اللوحة؟**
- ✏️ تعديل كل النصوص (عربي/إنجليزي) بالتبديل بين اللغتين من الأعلى.
- 🖼️ رفع **صورتك الشخصية** و**صور المشاريع** من جهازك (تُضغط تلقائياً وتُخزَّن على الخادم).
- ➕ إضافة / حذف / ترتيب المشاريع والخدمات والمهارات والمؤهلات.
- ⚙️ تعديل بيانات التواصل (الهاتف، البريد، الروابط) من تبويب «الإعدادات».
- ✅ **حفظ على الموقع** — يحفظ المحتوى في KV فيظهر على الموقع **فوراً** بدون إعادة نشر.
- 📥 **طلبات السيرة** — عرض طلبات تنزيل السيرة الذاتية، وقبولها أو رفضها.
- 📄 **ملف السيرة** — رفع ملف PDF (عربي/إنجليزي) بشكل **خاص** (لا يُنشر كرابط مباشر).
- 👁 **معاينة** — فتح الموقع في تبويب جديد لعرض التعديلات.
- ↺ **استرجاع** — إلغاء كل التعديلات والعودة للمحتوى الأصلي.
- 🚀 **نشر** — خيار متقدّم: رفع ملفات الموقع إلى GitHub مباشرة.

**الترتيب المقترح للعمل:**
1. عدّل ما تريد في اللوحة.
2. اضغط **✅ حفظ على الموقع** — يظهر التعديل على الموقع مباشرة.
3. (اختياري) اضغط **👁 معاينة** للتأكد في تبويب جديد.

> 🔒 **ملاحظة أمنية:** اللوحة محمية بكلمة مرور على الخادم، والجلسة في كوكي `HttpOnly`. لا تشارك كلمة المرور.
> رمز GitHub (للنشر) يُحفظ في متصفحك فقط ولا يُرسل لأي جهة غير GitHub.
> صفحة `admin.html` مُستثناة من محركات البحث في `robots.txt` (`noindex`).

## كيف تعدّل المحتوى يدوياً؟ (اختياري)
كل النصوص (عربي/إنجليزي) موجودة في ملف واحد: `assets/js/data.js`.
- لتغيير اسم مشروع أو وصفه: عدّل `projects.items`.
- لإضافة خدمة: أضف عنصراً جديداً في `services.items`.
- لتحديث المهارات/الشهادات: عدّل `skills.groups` و `qualifications`.

## تفعيل نموذج التواصل (إرسال حقيقي)
النموذج لا يُظهر رسالة نجاح وهمية. لتفعيل الإرسال الفعلي:
1. أنشئ حساباً مجانياً على [Formspree](https://formspree.io) أو [Web3Forms](https://web3forms.com).
2. احصل على رابط الـ endpoint الخاص بك.
3. أضف السطر التالي في `assets/js/data.js` داخل `meta`:
   ```js
   formEndpoint: "https://formspree.io/f/xxxxxxx",
   ```
سيبقى النموذج حتى ذلك الحين يوجّه الزائر للتواصل المباشر عبر البريد أو واتساب (بدون ادعاء إرسال).

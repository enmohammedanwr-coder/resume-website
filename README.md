# الموقع الشخصي — محمد أنور يحي أحمد عمران

موقع شخصي احترافي يجمع بين السيرة الذاتية الإلكترونية، معرض المشاريع، الخدمات التقنية، المهارات، والمؤهلات والشهادات.

## المميزات
- تصميم عصري داكن/فاتح (Dark/Light) مع لمسات زرقاء وسماوية.
- دعم كامل للغة العربية (RTL) والإنجليزية (LTR) مع زر تبديل فوري.
- متجاوب بالكامل مع الكمبيوتر والهاتف والأجهزة اللوحية.
- حركات انتقالية وتأثيرات بصرية هادئة + خلفية جسيمات تفاعلية.
- نافذة تفاصيل لكل مشروع، وزر "طلب خدمة" يوجّه إلى نموذج التواصل.
- نموذج تواصل مع تحقق كامل من صحة البيانات + حماية من الرسائل المزعجة (Honeypot).
- تحسين محركات البحث (SEO): Meta tags، Open Graph، Twitter Cards، Structured Data (JSON-LD).
- زر تحميل السيرة الذاتية PDF.

## البنية
```
index.html                الصفحة الرئيسية
assets/
  css/style.css           نظام التصميم الكامل
  js/data.js              ← ملف المحتوى (عدّل هنا فقط)
  js/app.js               منطق الموقع (ترجمة، ثيم، نماذج...)
  img/                    صور المشاريع والصورة الشخصية
  cv/                     ملف السيرة الذاتية PDF
  fonts/                  خطوط عربية
make_images.py            توليد صور المشاريع
make_cv.py                توليد السيرة الذاتية PDF
```

## كيف تعدّل المحتوى؟
كل النصوص (عربي/إنجليزي) موجودة في ملف واحد: `assets/js/data.js`.
- لتغيير اسم مشروع أو وصفه: عدّل `projects.items`.
- لإضافة خدمة: أضف عنصراً جديداً في `services.items`.
- لتحديث المهارات/الشهادات: عدّل `skills.groups` و `qualifications`.

## تفعيل نموذج التواصل (إرسال حقيقي)
النموذج لا يُظهر رسالة نجاح وهمية. لتفعيل الإرسال الفعلي:
1. أنشئ حساباً مجانياً على [Formspree](https://formspree.io) أو [Web3Forms](https://web3forms.com).
2. احصل على رابط الـ endpoint الخاص بك.
3. أضف السطر التالي في `assets/js/data.js` داخل `meta`:
   ```js
   formEndpoint: "https://formspree.io/f/xxxxxxx",
   ```
سيبقى النموذج حتى ذلك الحين يوجّه الزائر للتواصل المباشر عبر البريد أو واتساب (بدون ادعاء إرسال).
